## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/boggavarapu-manoz-kumar/portfolio-.git
```

```bash
cd portfolio-system
```

---

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

### Backend Setup

Configure your database in:

```properties
application.properties
```

Run Spring Boot:

```bash
./mvnw spring-boot:run
```
